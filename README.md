# Channel Deck

自分の YouTube チャンネルの分析と、伸びている動画の傾向チェックを、スマホからも見られるようにした個人用ツールです。複数チャンネルを連携して切り替えられます。

## できること

- **ホーム**: 視聴回数・総再生時間・登録者の増減・平均視聴時間・推定収益(収益化している場合)を、直前の同じ長さの期間と比較。日別の推移、長尺/ショート/ライブ別の内訳、流入元、視聴者の年齢層と性別、よく見られた動画。
- **動画**: 自分の投稿(新しい順に最大100本)を、長尺/ショートで絞り込み、再生数・勢い・高評価率で並べ替え。
- **トレンド**: 国内の急上昇(カテゴリ別)、キーワードと期間で「伸びている動画」を検索、参考にしたいチャンネルの登録(最大12件)。それぞれ、再生数の中央値・ショートの割合・長さ・公開の多い時間帯・タイトルの付け方・よく出る言葉とタグをまとめて表示。

扱うのは閲覧だけです。動画の編集やコメント返信など、チャンネルを変更する操作はしません(Google に求める権限も読み取り専用です)。

### 知っておくとよい制限

- ショートかどうかを示す正式な項目が API に無いため、動画一覧とトレンドでは **3分以下をショートと推定** しています。ホームの「動画の種類別」だけは YouTube 側の正式な区分です。
- カット割りやテロップといった **編集の中身は API から取得できません**。傾向として出せるのは、長さ・タイトル・タグ・公開時刻・サムネイルです。
- YouTube アナリティクスは反映に2日ほどかかるため、ホームの期間は2日前までです。
- YouTube Data API には1日の利用枠(標準で10,000)があります。キーワード検索と、名前での参考チャンネル追加は1回で100消費します(同じ条件の結果は1時間使い回します)。

## デモモード

Google の認証情報(`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`)を設定していないあいだは、サンプルデータで動きます。画面の確認用で、数字や動画はすべて作り物です。

```bash
npm install
```

```bash
npm run dev
```

## 本番で使うための設定

### 1. Vercel にデプロイする

1. [Vercel](https://vercel.com/) でこのリポジトリをインポートします(設定は初期値のままで構いません)。
2. デプロイ後の URL(例: `https://xxxx.vercel.app`)を控えます。この時点ではデモモードで表示されます。

### 2. Google Cloud で OAuth クライアントを作る

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作ります。
2. 「API とサービス」→「ライブラリ」で **YouTube Data API v3** と **YouTube Analytics API** を有効にします。
3. 「OAuth 同意画面」を設定します(対象: 外部)。設定後、**公開ステータスを「本番環境」に** してください。「テスト」のままだと、連携が7日で切れます。自分だけで使う場合、審査は不要です(連携時に「確認されていないアプリ」という警告が出るので、「詳細」から進みます)。
4. 「認証情報」→「OAuth クライアント ID」を作ります。
   - 種類: ウェブ アプリケーション
   - 承認済みのリダイレクト URI: `https://(デプロイしたURL)/api/oauth/callback`
5. 表示されたクライアント ID とクライアント シークレットを控えます。

### 3. 環境変数を設定する

Vercel の「Settings」→「Environment Variables」に次を登録し、再デプロイします。

| 名前 | 内容 |
|---|---|
| `APP_PASSWORD` | このツールに入るためのパスワード。URL を知っている人なら誰でも入力画面に来られるので、長いものにしてください |
| `SESSION_SECRET` | 暗号化と署名に使う32文字以上のランダムな文字列(`openssl rand -base64 32` で作れます) |
| `GOOGLE_CLIENT_ID` | 手順2のクライアント ID |
| `GOOGLE_CLIENT_SECRET` | 手順2のクライアント シークレット |
| `APP_URL`(任意) | 公開 URL を固定したい場合(独自ドメインなど)。リダイレクト URI もこの URL に合わせます |

Google の認証情報を設定すると、`APP_PASSWORD` と `SESSION_SECRET` が無い状態では動きません(誰でも見られる状態を防ぐためです)。

### 4. チャンネルを連携する

ツールを開いてパスワードでログインし、「アカウント」→「Google アカウントでチャンネルを追加」を押します。チャンネルを持つ Google アカウントを選び、表示される権限をすべて許可してください。2つ目以降のチャンネルも同じ手順で追加できます。

スマホでは、ブラウザの「ホーム画面に追加」でアプリのように開けます。

## 連携情報の保存先

- **初期状態**: 連携情報(Google の更新トークン)は暗号化して、端末のブラウザの Cookie に保存します。追加の契約は不要ですが、**端末ごとに連携が必要** です(スマホと PC で使うなら、それぞれで連携します)。
- **Upstash Redis を使う場合**: Vercel の Marketplace から Upstash Redis を追加する(または `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` を設定する)と、サーバー側に暗号化して保存され、一度の連携でどの端末からも見られます。切り替えたあとは、もう一度チャンネルを連携してください。

`SESSION_SECRET` を変更すると、保存済みの連携情報は読めなくなります(再連携が必要です)。

## 開発

```bash
npm test
```

```bash
npm run build
```

- `lib/` … 認証、保存、Google API の呼び出し、傾向の集計
- `app/` … 画面(Next.js App Router)
- `components/` … グラフや動画リストなどの部品
- `tests/` … 表示形式・集計・暗号化の単体テスト
